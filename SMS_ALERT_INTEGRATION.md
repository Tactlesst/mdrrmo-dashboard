# SMS Alert Integration Guide

## Overview
The MDRRMO Dashboard now includes functionality to create emergency alerts from SMS messages received from the resident mobile app. This allows administrators to quickly process emergency SMS messages and convert them into trackable alerts in the system.

## How It Works

### SMS Message Format
The system expects SMS messages in this format:
```
send From 09516569463
[Emergency message content]
Location: [Address or description]
Coords: [latitude,longitude]
```

### Example SMS Messages
```
send From 09516569463
Boom
Location: Lat: 8.745413, Lon: 124.777581
Coords: 8.74541,124.77758
```

```
send From 09516569463
Tt
Location: Valmores Street, 77, Misamis Oriental, Balingasag, Northern Mindanao
Coords: 8.74541,124.77758
```

## Using the SMS Alert Feature

### Step 1: Access the SMS Parser
1. Open the **Verify Incidents** section in the dashboard
2. Click the **"Add SMS Alert"** button in the top-right corner
3. The SMS parser modal will open

### Step 2: Parse SMS Message
1. Copy the entire SMS message from your phone or SMS app
2. Paste it into the text area in the SMS parser
3. The system will automatically parse:
   - **Phone Number**: Extracted from "send From" line
   - **Message Content**: Emergency description
   - **Location**: Address or coordinate description
   - **Coordinates**: Latitude and longitude values

### Step 3: Create Alert
1. Click **"Create Alert"** button
2. The system will:
   - Validate the coordinates
   - Create a new alert in the database
   - Add it to the unverified alerts list
   - Show success confirmation

### Step 4: Verify and Process
1. The new alert appears in the verification queue
2. Review the alert details:
   - **Contact**: Phone number from SMS
   - **Location**: Parsed address and coordinates
   - **Description**: Message content
   - **Source**: Marked as "SMS"
3. Verify or refer the alert as needed

## Technical Details

### SMS Parsing Logic
The parser extracts information using these patterns:
- **Phone Number**: Regex `(\d{11}|\+?\d{12,13})` from "send From" line
- **Location**: Text after "Location:" prefix
- **Coordinates**: Regex `([\d.-]+)[,\s]+([\d.-]+)` from "Coords:" line
- **Message**: All other non-metadata lines

### Database Fields
SMS alerts are created with these fields:
```javascript
{
  type: 'Emergency',
  lat: [parsed latitude],
  lng: [parsed longitude], 
  address: [parsed location or coordinates],
  description: [parsed message content],
  occurred_at: [current timestamp],
  contact: [parsed phone number],
  source: 'SMS',
  created_by: [admin name],
  severity: 'high',
  status: 'pending',
  verified: false
}
```

### API Endpoint
- **URL**: `/api/alerts/create-from-sms`
- **Method**: POST
- **Validation**: Coordinates, required fields
- **Response**: Success/error with alert details

## Error Handling

### Invalid SMS Format
- Missing coordinates → "Invalid SMS Format" error
- Malformed coordinates → Validation error
- Empty message → "Empty Message" warning

### Database Errors
- Duplicate alerts → 409 Conflict
- Missing fields → 400 Bad Request
- Server errors → 500 Internal Server Error

### Coordinate Validation
- Latitude: -90 to 90 degrees
- Longitude: -180 to 180 degrees
- Must be valid numbers

## Benefits

1. **Quick Processing**: Convert SMS to alerts in seconds
2. **Accurate Parsing**: Automatically extracts all relevant data
3. **Geo-Location**: Preserves exact coordinates from mobile app
4. **Contact Tracking**: Maintains phone number for follow-up
5. **Audit Trail**: Marks source as SMS with admin who created it
6. **Integration**: Works with existing verification workflow

## Usage Tips

1. **Copy Full Message**: Include all lines from the SMS
2. **Check Coordinates**: Verify location makes sense before creating
3. **Add Notes**: Use verification notes for additional context
4. **Immediate Response**: SMS alerts default to "high" severity
5. **Follow Up**: Use contact number for direct communication

## Troubleshooting

### Common Issues
1. **"Invalid SMS Format"**: Check if coordinates line is present
2. **"Missing required field"**: Ensure latitude/longitude are valid numbers
3. **"Duplicate alert"**: Alert with same details may already exist

### Format Requirements
- Phone numbers: 11 digits (09XXXXXXXXX) or international format
- Coordinates: Decimal format (8.74541,124.77758)
- Location line: Must start with "Location:"
- Coords line: Must start with "Coords:"

### Best Practices
1. Process SMS messages promptly
2. Verify location accuracy on map
3. Contact sender if details unclear
4. Document any additional context in notes
5. Refer to appropriate authorities when needed

## Integration with Mobile App

The SMS messages are generated by the resident mobile app when:
- Network connectivity is unavailable
- User chooses SMS fallback option
- Emergency situation requires offline communication

This ensures emergency alerts reach MDRRMO even when internet connectivity is poor or unavailable.
